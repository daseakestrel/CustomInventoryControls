# Custom Inventory Control

This mods changes the PDA behavior to allow the player to close 
it using the Escape key. You can still close with the PDA's 
default primary (or secondary) key.

# Libraries

- [BepInEx](https://github.com/BepInEx/BepInEx)
- [HarmonyX](https://github.com/BepInEx/HarmonyX)
- [Template from Nautilus Wiki](https://www.nuget.org/packages/Subnautica.Templates)
